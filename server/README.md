# PC Cleaner Dashboard

שרת קטן (Python בלבד, בלי תלויות) שמקבל לוגים ודוחות מהתוכנה, מציג את רשימת המחשבים,
ומספק את הגרסה האחרונה להורדה ולעדכון אוטומטי.

משתני סביבה:
- INGEST_KEY (לפחות 16 תווים): מפתח שהתוכנה משתמשת בו. SECRET_KEY: חתימת עוגיות.
- DASH_PASSWORD (לפחות 6): סיסמת הדשבורד.
- UPDATE_REPO: ריפו העדכונים הפרטי, בצורה owner/repo.
- GITHUB_TOKEN: חובה לריפו עדכונים פרטי (Contents: Read). לריפו ציבורי אופציונלי, ומונע מגבלת קצב.
- DB_PATH, PORT: אופציונלי.

הערה: בתוכנית החינמית ב-Render מערכת הקבצים זמנית, ולכן לוגים נמחקים בהפעלה מחדש או בהרדמה.
לשמירה קבועה: דיסק קבוע בתשלום עם DB_PATH=/var/data/pccleaner.db.
